# TIME TRACKERS - Smart Classroom & Time Table Scheduler

A comprehensive web application for managing smart classrooms and scheduling time tables, built with React.

## Features

### 🔐 Authentication System
- Role-based login (Student, Faculty, Admin)
- Education level selection (School, Intermediate, UG, PG)
- Secure user authentication

### 📅 Time Table Scheduler
- Add and manage teachers, subjects, rooms, and classes
- Generate optimized timetables
- View timetables from different perspectives (student/faculty)
- Dynamic scheduling with conflict resolution

### 🎓 Smart Classroom
- **Video Library**: Upload and manage educational videos
- **Emotion Detection**: Real-time AI-powered emotion analysis
- **Global Exchange**: Connect with international educators and guest lectures
- **Gamification**: XP system, badges, and leaderboards
- **Virtual Assistant**: ClassBot for instant help and suggestions
- **Feedback System**: Anonymous student feedback collection
- **Dynamic Rescheduling**: Automatic adjustments for cancellations

## Installation & Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm start
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```
